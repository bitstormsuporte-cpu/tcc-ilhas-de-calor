Análise de Impacto

Selecione um ponto no mapa e altere o nível do tráfego para simular o estresse biometeorológico.

⚙️ Opção avançada: usar outra chave de API
O app já vem com uma chave configurada e funciona sozinho em qualquer computador. Só preencha aqui se quiser usar sua própria chave pessoal. Usada para medir o trânsito em tempo real. Também já vem configurada por padrão.
No modo automático, o trânsito é medido em tempo real perto do ponto selecionado. Se não houver dado suficiente para aquele bairro, o app avisa e usa a última opção manual escolhida.
